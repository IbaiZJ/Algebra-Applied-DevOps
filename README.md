# Hospital Management

This project is a hospital management application that centralizes information and day-to-day tasks. It aims to help organize patients, staff, and resources while making healthcare services more efficient.

## Project board

The work is tracked on the GitHub Project: https://github.com/users/IbaiZJ/projects/9.

## 1. Project overview

This project aims to develop a hospital management application that brings essential workflows together in one place. It will support the management of patients, doctors, appointments and medical records, with role-based access to help staff coordinate care efficiently and protect sensitive information.
